# Сборка FunPay Searcher в один исполняемый файл

Приложение можно собрать в один файл `FunPaySearcher.exe` (PyInstaller, режим `--onefile`), который не требует
установленного Python: достаточно скопировать exe в любую папку и запустить. Размер файла — около 30 МБ
(внутри — интерпретатор Python, все библиотеки, веб-интерфейс и эталонные профили).

Сборка для Windows делается **на Windows** (`build_exe.bat`), для Linux/macOS — `build_exe.sh`.
PyInstaller не умеет кросс-компилировать: собрать exe для Windows на Linux нельзя.

## Что нужно

* Windows 10/11 x64 (для Linux/macOS — любой современный дистрибутив; `build_exe.sh` проверен на Linux).
* Python 3.11+ с <https://www.python.org/downloads/> (сборка проверена на Python 3.13 и PyInstaller 6.22). При установке обязательно
  поставьте галочку **"Add Python to PATH"** — иначе `build_exe.bat` не найдёт `python`.
* Доступ в интернет: при первой сборке скрипт создаёт виртуальное окружение `.venv` и ставит туда зависимости
  из `requirements.txt` и сам `pyinstaller`.
* Около 500 МБ свободного места (`.venv` + промежуточные файлы в `build\`).

## Сборка на Windows

1. Распакуйте/склонируйте проект, откройте папку проекта.
2. Запустите `build_exe.bat` двойным щелчком (или из `cmd`: `build_exe.bat`).
3. Дождитесь строки `[OK] Готово: dist\FunPaySearcher.exe`. Первая сборка занимает 2–5 минут
   (установка зависимостей), повторные — около минуты.
4. Готовый файл — `dist\FunPaySearcher.exe`. Промежуточные файлы (`build\`, `build\FunPaySearcher.spec`)
   можно удалить, в git они не попадают.

Что делает скрипт:

* проверяет, что `python` есть в PATH; создаёт `.venv`, если его нет;
* `pip install -r requirements.txt pyinstaller`;
* запускает PyInstaller с параметрами:

| Параметр | Зачем |
|---|---|
| `--onefile --name FunPaySearcher` | один exe-файл с таким именем |
| `--clean --noconfirm` | не использовать кэш прошлой сборки, не задавать вопросов |
| `--distpath dist --workpath build --specpath build` | результат в `dist\`, всё временное — в `build\` |
| `--paths <папка проекта>` | чтобы PyInstaller нашёл пакет `app` |
| `--add-data app\web\static;app\web\static` | веб-интерфейс (HTML/JS/CSS) |
| `--add-data config\settings.example.yaml;config` | шаблон настроек |
| `--add-data config\profiles;config\profiles` | эталонные профили поиска |
| `--collect-submodules app` | все модули `app.*`, включая те, что импортируются лениво (`app.notify`, `app.services.orders`, `app.services.raiser` и т. д.) |
| `--collect-submodules uvicorn` | uvicorn подбирает event loop и HTTP-протокол динамически |
| `--hidden-import bs4.builder._lxml`, `lxml.etree`, `lxml._elementpath` | парсер HTML (`BeautifulSoup(..., "lxml")`) |

Пути в `--add-data` указаны абсолютными через `%~dp0`, потому что PyInstaller считает относительные пути
от папки `.spec`-файла (`build\`), а не от папки проекта. Разделитель «источник;назначение» на Windows — `;`,
на Linux/macOS — `:`.

## Сборка на Linux / macOS

```bash
./build_exe.sh                       # результат: dist/FunPaySearcher
DIST_DIR=/tmp/out ./build_exe.sh     # положить результат в другую папку
```

Переменные окружения: `PYTHON` (интерпретатор для создания `.venv`, по умолчанию `python3`),
`DIST_DIR` (куда класть результат, по умолчанию `dist`), `WORK_DIR` (временные файлы и `.spec`, по умолчанию `build`).
Параметры PyInstaller те же, что в `build_exe.bat`.

## Где exe ищет настройки и данные

Папки определяются по расположению **самого exe-файла** (`sys.executable`), а не по текущей папке,
из которой его запустили — ярлык с другим «рабочим каталогом» ничего не ломает:

```
FunPaySearcher.exe
config\
    settings.yaml            ← ваши настройки (создаётся при первом запуске из settings.example.yaml)
    settings.example.yaml    ← шаблон с комментариями
    profiles\*.yaml          ← профили поиска (10 эталонных копируются при первом запуске)
data\
    searcher.db              ← база SQLite (находки, лоты, заказы, журнал)
    app.log                  ← лог приложения
```

* При первом запуске exe создаёт `config\` и `data\` рядом с собой: копирует `settings.example.yaml`,
  создаёт `settings.yaml` и копирует профили (только если в `config\profiles\` ещё нет ни одного `*.yaml`).
* Поэтому **кладите exe в отдельную папку** — например, `C:\FunPaySearcher\`.
* Обновление: замените только exe, `config\` и `data\` сохраняются. Перенос — переносите всю папку.
* Переменные окружения `FUNPAY_GOLDEN_KEY`, `LOLZ_TOKEN`, `TELEGRAM_BOT_TOKEN` имеют приоритет над `settings.yaml`.
* Ресурсы сборки (веб-интерфейс, шаблон настроек, эталонные профили) распаковываются при каждом запуске во
  временную папку `%TEMP%\_MEIxxxxxx` и удаляются при выходе; править их там бессмысленно.

Запуск: двойной щелчок по exe — откроется консольное окно с логом и браузер с интерфейсом
(адрес по умолчанию <http://127.0.0.1:8787/>). Закрыть окно или нажать Ctrl+C — остановить сервер.
Параметры командной строки: `--port 8790`, `--host 0.0.0.0`, `--no-browser`, `--debug`.

## Как проверить сборку

1. Скопируйте `dist\FunPaySearcher.exe` в **пустую** папку и запустите: `FunPaySearcher.exe --no-browser --port 8798`.
2. Рядом должны появиться `config\settings.yaml`, `config\profiles\` (10 файлов) и `data\`.
3. Откройте <http://127.0.0.1:8798/> — должен открыться интерфейс; <http://127.0.0.1:8798/api/profiles> — список из 10 профилей.
4. Нажмите «Искать» (или `POST /api/search`): без ключей в журнале появятся предупреждения
   «не задан токен/cookie в настройках — источник пропущен» — это ожидаемо и означает, что сборка рабочая.

## Если что-то пошло не так

**Антивирус / SmartScreen ругается на exe.** Это ложное срабатывание, типичное для PyInstaller `--onefile`:
exe сам себя распаковывает во временную папку, что похоже на поведение упаковщиков вредоносного ПО, а файл не
подписан. Что делать: собрать exe самостоятельно из исходников (готовые exe из непроверенных источников
не используйте), добавить папку с exe в исключения антивируса, в SmartScreen нажать «Подробнее → Выполнить
в любом случае». Если срабатывание повторяется, соберите в режиме папки — замените `--onefile` на `--onedir`
в `build_exe.bat` (получится папка `dist\FunPaySearcher\` с exe внутри; антивирусы относятся к ней спокойнее,
а запуск быстрее). Загруженный в `%TEMP%` файл можно также проверить на VirusTotal.

**`[!] Python не найден` / `'python' is not recognized`.** Python не установлен или не добавлен в PATH.
Переустановите Python с галочкой **"Add Python to PATH"** (или добавьте папки `Python3xx\` и
`Python3xx\Scripts\` в переменную PATH вручную) и откройте новое окно `cmd`. Если вместо установки открывается
Microsoft Store — отключите псевдонимы `python.exe`/`python3.exe` в «Параметры → Приложения → Дополнительные
параметры приложений → Псевдонимы выполнения приложений».

**Порт занят** (`ERROR: [Errno 10048] error while attempting to bind on address ... only one usage of each socket
address` или `address already in use`; строка «FunPay Searcher запущен» перед ней печатается до попытки занять порт
и ничего не значит). Другая копия программы уже запущена (посмотрите в трее/диспетчере задач) или порт 8787 занят другим
приложением. Запустите с другим портом: `FunPaySearcher.exe --port 8790` — или измените `ui.port` в
`config\settings.yaml`. Узнать, кто занял порт: `netstat -ano | findstr :8787`, затем PID в диспетчере задач.

**Окно открылось и сразу закрылось.** Запустите exe из `cmd` (`cd` в папку, затем `FunPaySearcher.exe`) —
текст ошибки останется на экране; также смотрите `data\app.log`. Частые причины: занят порт (см. выше),
нет прав на запись в папку (например, `C:\Program Files\`) — перенесите exe в папку пользователя,
повреждённый `config\settings.yaml` — переименуйте его, при следующем запуске создастся новый.

**`ModuleNotFoundError` / `No module named ...` только в exe, в `python -m app` всё работает.**
PyInstaller не увидел импорт (обычно — динамический). Добавьте `--hidden-import имя.модуля` в `build_exe.bat`
(новые модули `app.*` подхватываются автоматически через `--collect-submodules app`). Список того, что PyInstaller
не нашёл, — в `build\FunPaySearcher\warn-FunPaySearcher.txt` (большинство записей там — безобидные
необязательные зависимости библиотек).

**Браузер не открылся.** Откройте адрес из консоли вручную (по умолчанию <http://127.0.0.1:8787/>).
Автооткрытие отключается ключом `--no-browser` или `ui.open_browser: false` в настройках.

**Медленный запуск (5–15 секунд).** Нормально для `--onefile`: при каждом старте ~30 МБ распаковываются в `%TEMP%`,
а антивирус их проверяет. Помогают исключение в антивирусе или сборка `--onedir`.

**Сборка падает с `PermissionError` на `dist\FunPaySearcher.exe`.** Предыдущая копия exe ещё запущена —
закройте её (или антивирус держит файл; подождите и повторите).
