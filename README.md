# FunPay Searcher

Локальное приложение для дропшиппинга игровых аккаунтов: **одной кнопкой** ищет аккаунты на
**FunPay** и **Lolzteam Market** по вашим критериям (World of Tanks, Dota 2, CS2, Fortnite, Genshin и т.д.),
**создаёт лоты на FunPay** в вашем оформлении с заданной наценкой и **следит**, не продали ли исходный аккаунт.

Работает на вашем компьютере (Windows / macOS / Linux), интерфейс открывается в браузере по адресу
`http://127.0.0.1:8787`. Никаких облаков: все данные (ключи, находки, лоты) лежат в папке проекта.

## Быстрый старт

1. Установите [Python 3.11+](https://www.python.org/downloads/) (на Windows поставьте галочку *Add Python to PATH*).
2. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
3. Запустите **`run.bat`** (Windows) или **`./run.sh`** (macOS / Linux). Первый запуск установит зависимости.
4. В открывшемся окне браузера зайдите в **Настройки** и вставьте:
   * **FunPay `golden_key`** — cookie с сайта funpay.com. В браузере: F12 → Application (Приложение) → Cookies →
     `https://funpay.com` → значение `golden_key`. Там же скопируйте свой **User-Agent** (кнопка в настройках
     подставит его автоматически, если вы открыли интерфейс из того же браузера).
   * **Токен Lolzteam** — создаётся на https://lolz.team/account/api (нужен доступ к Market).
5. Нажмите **«Проверить подключение»**, затем на главной — **«🔍 Найти аккаунты»**.

## Как это работает

```
Профили (config/profiles/*.yaml)      →  Поиск  →  Критерии  →  Кандидаты  →  Лот на FunPay  →  Монитор
  игра / регион / фильтры / наценка        FunPay      must/exclude    цена с наценкой   «в нашем стиле»    исходник продан?
  шаблон оформления лота                   Lolzteam    highlights      ссылка на продавца                   → снять лот
```

* **Профиль** — один файл YAML на игру+регион: где искать (категория FunPay, категория и параметры Lolz),
  критерии (цена, обязательные слова, стоп-слова, регулярные выражения, числовые поля), правило наценки,
  шаблон заголовка и описания лота. Профили редактируются в интерфейсе (раздел «Профили») или прямо в файлах.
* **Критерии** — например, для танков: `must_any: ["все топы", "chieftain|чифтейн", "об 279"]`,
  `exclude: ["бан", "без почты"]`, `regions: ["RU"]`. Для Dota 2: регулярка `(\d{4,5})\s*(mmr|ммр)` плюс
  `must_any: ["immortal", "аркан|arcana"]`. Кнопка «Проверить критерии» показывает, почему объявление прошло или нет.
* **Наценка** — проценты, множитель, ступени или формула. Пример из ТЗ «15 000 → 29 000, 30 000 → 59 000»
  это формула `price * 2 - 1000` с округлением до 100.
* **Лот** — заголовок/описание собираются из шаблона с плейсхолдерами (`{game}`, `{region}`, `{highlights}`,
  `{price}`, `{attr[steam_level]}` …). Сначала создаётся **черновик**: вы видите предпросмотр, правите и жмёте
  «Создать на FunPay». В настройках можно включить `auto_publish`, тогда лоты публикуются без подтверждения.
* **Монитор** — раз в N минут проверяет исходные объявления (по сохранённой ссылке) и, если аккаунт продан
  или снят, автоматически **деактивирует ваш лот** и помечает находку как «продано». Ссылка на продавца
  сохраняется у каждого лота.
* **Продажи** — приложение следит за заказами на FunPay: как только ваш лот купили, заказ появляется в
  разделе «Продажи» со ссылкой «Купить исходник» (куда идти за аккаунтом), ценой закупки и маржой.
* **Автоподнятие** — раз в N часов нажимает «Поднять» для категорий, где у вас есть активные лоты.
* **Репрайсинг** — если продавец исходника поменял цену, приложение пересчитывает цену вашего лота по правилу
  профиля (или только напоминает, если автопересчёт выключен) и обновляет рекомендуемые цены кандидатов.
* **Автоответчик** — отвечает покупателям в чате FunPay по ключевым словам («в наличии?» → «Да, в наличии ✅»)
  или общим приветствием, не чаще одного раза в N часов на чат, и пересылает новые сообщения в Telegram.
* **Telegram** — бот присылает новые подходящие аккаунты, проданные исходники и новые заказы.
* **Экспорт** — находки, лоты и заказы выгружаются в CSV (открывается в Excel).
* **Рынок** — для каждой находки показывается статистика цен похожих аккаунтов (мин/медиана/макс),
  чтобы не завысить и не занизить цену.

## Если что-то не работает: диагностика

В разделе «Настройки» нажмите **«Запустить диагностику»** (или запустите `run.bat --diagnose`). Приложение
проверит авторизацию, разметку списков лотов, страницу лота, форму создания лота, заказы и чаты FunPay, а также
API Lolz, и сохранит обезличенные снимки страниц в `data/diagnostics/`. Пришлите эту папку разработчику — по ней
селекторы чинятся за один заход. Личные данные (cookie, токены, имена, переписка, баланс) в снимки не попадают.
Подробнее: [docs/DIAGNOSTICS.md](docs/DIAGNOSTICS.md).

## Структура

```
run.bat / run.sh          запуск одним кликом
config/settings.yaml      ключи и параметры (создаётся из settings.example.yaml)
config/profiles/*.yaml    21 профиль поиска по играм (см. docs/PROFILES.md)
data/searcher.db          база находок и лотов (SQLite), data/app.log — лог
app/sources/funpay.py     клиент FunPay (поиск, страница лота, создание/редактирование лотов)
app/sources/lolz.py       клиент Lolzteam Market API
app/matching.py           движок критериев
app/templating.py         шаблоны лотов
app/pricing.py            наценка
app/services/             поиск, публикация, монитор, заказы, автоподнятие, репрайсинг, автоответчик
app/sources/funpay_chat.py чат FunPay (список чатов, история, отправка сообщений)
app/notify.py             уведомления в Telegram
app/diagnostics.py        самодиагностика FunPay/Lolz
tests/e2e/                сквозные тесты интерфейса (Playwright)
app/main.py               HTTP API (документация: http://127.0.0.1:8787/api/docs)
app/web/static/           интерфейс
```

## Запуск из консоли

```
python -m app --port 8787 --no-browser
```

## Сборка в один exe (Windows)

Запустите `build_exe.bat` — появится `dist\FunPaySearcher.exe` (на Linux/macOS — `./build_exe.sh`, результат `dist/FunPaySearcher`).
Положите его в отдельную папку: при первом запуске рядом создадутся `config\` (настройки и профили) и `data\` (база, лог).
Параметры сборки и решение проблем (антивирус, «Add Python to PATH», занятый порт) — в [docs/BUILD.md](docs/BUILD.md).

## Важно

* Парсинг FunPay опирается на HTML сайта. Если FunPay поменяет вёрстку, нужно будет обновить селекторы в
  `app/sources/funpay.py` — в журнале приложения будет понятная ошибка.
* Названия фильтров Lolz (например `dota2_solo_mmr_min`) проверяйте кнопкой «Параметры категории» в редакторе
  профиля — она запрашивает актуальный список у API.
* Соблюдайте паузы между запросами (настройки `request_delay`): это защищает ваш аккаунт от блокировки за
  слишком частые запросы.
